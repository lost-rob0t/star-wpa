* Design

Independent python -m star_wpa.privacy CLI/library; no adapter ingestion or custody pathway. Bounded strict UTF-8 CSV/JSON parsing, known exact headers and envelope keys, numeric/coordinate validation. Reduce inputs immediately to typed coordinate/radio/signal observations. Inclusive latitude/longitude boxes support antimeridian crossing; expand conservatively by meter buffers on a sphere, including polar coverage. Optional coarse coordinate rounding follows exclusion and repeats exclusion to avoid rounding back into a protected area. Output contains only latitude, longitude, radio, signal_dbm; sort and deduplicate retained tuples so source sequence/multiplicity is removed. Default coarse precision is 2 decimals. No metadata, original identifiers, names, timestamps, hashes, paths or exclusion geometry is serialized.

Preview server binds 127.0.0.1 with exact Host/Origin validation and per-process request token, no CORS/logging/storage/outbound calls. Bundled offline coordinate plot and controls issue POSTs; preview must precede export, export uses the exact preview result. Source and destination are CLI-selected local paths; HTTP clients cannot choose paths. All path components are opened relative to directory descriptors using O_NOFOLLOW; export uses O_EXCL mode 0600. Explicitly describe retained-location disclosure and noncompatibility with WiGLE upload.
