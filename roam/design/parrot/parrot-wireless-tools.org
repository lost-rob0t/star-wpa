* Design

Maintain an immutable upstream stanza plus hash and a catalog containing every listed package. Add 26 adjacent wireless utilities as explicit supplemental entries, never silently label them upstream membership. Generate per-package .star actor declarations from this source and execute them on the same maintained runtime.

Discover installed package executables with dpkg-query, verify real ownership and resolve exact basenames. Provide discover and execute operations, stdin and terminal/desktop requirements, bounded subprocess groups, output byte limits, redacted hash/length receipts and existing at-most-once admission. Every execute argv, working directory, stdin file and UI mode must exactly match deployment-local approved command descriptors. The request cannot authorize itself.

This is full package-level discovery/invocation coverage, not a claim that every flag/output format or radio device is semantically normalized or hardware-tested. Specialized Kismet/GPSD/airodump/wardrive parsers remain the canonical radio observation adapters.

User subsequently requested evil-twin/phishing tool adapters and Nix flakes. Supplemental entries include Wifiphisher, EAPHammer and hostapd-wpe. Flakes pin nixpkgs, StarLang and Parrot sources; Python adapters, native runtime launcher, checks, development shell and an availability-labelled nixpkgs tool bundle are build outputs. Missing packages require an explicit operator-pinned installation; no substitute program is represented as the missing tool.

* Evaluation Gates

Prove source coverage equality, no missing generated declarations, each entry can traverse discovery and execution ports under policy, rejection of unowned binaries, missing packages/desktop, denial before effects, bounded timeout/output cleanup, native runtime registration and actual process execution. Run all existing schema/view/CouchDB and research gates plus CI before merging.
