* Design

Compile .star actor declarations using the maintained compiler and execute using the Common Lisp native runtime. Python owns external Kismet HTTP, GPSD TCP and exact argv tool adapters, normalization and numerical solving. Consume the complete immutable StarLang release via its existing sync script. Emit canonical event evidence, wireless records, geo-point/location and explicit relations. Receiver position is observation geography, never an inferred AP position. Trilateration joins at least three distinct receivers for the same dataset, transmitter and bounded time window; reject degenerate geometry and retain residuals and source evidence.

CouchDB map views expose observation joins, geo and relations. Numerical trilateration runs in the resolver actor, outside reduce: views index evidence and do not fabricate a CouchDB spatial engine. Active effects use bounded subprocess deadlines and explicit target-scoped local policy.
