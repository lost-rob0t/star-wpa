Kismet's official login documentation retrieved 2026-10-09 specifies a KISMET cookie or URI parameter for API tokens: https://www.kismetwireless.net/docs/api/login/. Star-WPA currently sends only a Bearer header. Direct Kismet compatibility therefore needs a cookie mode; preserve Bearer as the existing default for gateways. Never put tokens into URLs.

* Design

Add operator-local kismetTokenAuth with bearer (default) and cookie modes. Requests cannot override it. Cookie values must satisfy RFC 6265 cookie-octet constraints before transport. Both modes retain exact destination checks and redirect rejection. Add matching token-free example request/policy files and deployment guidance. Exercise the actual CLI subprocess against loopback servers with bounded waits; test missing/malformed policy, exact URL mismatches, request policy injection, secret selection, auth modes, redirects and canonical output.
