* Verified Findings

Kismet tokenEnv selects arbitrary process variables. Kismet and CouchDB use urllib default redirect forwarding. Specialized aircrack/deauth use unbounded output temporary files and do not own descendant process groups. Ledger creation follows symlinks and trusts existing permissions. Manifest and stdin reads bound size only before reads or after allocation.

* Design

Disable HTTP redirects while preserving proxies and TLS. Restrict Kismet to STAR_WPA_KISMET_TOKEN and require exact endpoint membership in local kismetTokenUrls before sending it. Reuse the bounded process-group runner for specialized active effects; discard unused capture diagnostics and fence descendants. Reject unsafe ledger ownership, links, modes and nonregular files. Read regular input files through opened descriptors with actual byte bounds; stage bounded stdin before launching.

* Evaluation

Regression tests use local HTTP endpoints, FIFO and unsafe ledger fixtures, bounded subprocess input/output, and existing at-most-once tests. Native/Nix/schema/views and live CouchDB gates run in CI. No hardware validation is claimed. Parent directories and executable installations remain operator-trusted; this is not an OS sandbox.
